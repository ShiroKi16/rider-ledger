# 라이더 가계부

배달 라이더를 위한 하루 단위 가계부입니다. 폰에 설치해서 인터넷 없이도 쓸 수 있는 웹앱(PWA)입니다.

- 수입: 배민 / 두 번째 수입처(이름은 앱에서 바꿀 수 있음), 건수·운행 시간
- 지출: 분류별 기록, 통장별 잔액
- 이체: 통장끼리 옮긴 돈 (지출로 잡히지 않음)
- 받을 돈: 배민 수입은 정산 전까지 따로 쌓였다가 "정산 들어왔어요"로 통장에 반영
- 백업: 기록을 JSON 파일로 저장하고 불러오기

기록은 기기 안(localStorage)에만 저장되며 서버로 보내지 않습니다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 전체 (화면, 계산, 저장) |
| `sw.js` | 오프라인 실행용 서비스 워커 |
| `manifest.webmanifest` | 설치용 앱 정보 |
| `icons/` | 앱 아이콘 |

## 업데이트할 때

`index.html`을 고친 뒤 `sw.js`의 `VERSION` 값을 바꿔서 올리면 됩니다.
인터넷이 되면 앱은 항상 최신 화면을 먼저 받아오고, 새 서비스 워커는 기다리지 않고 바로 교체되어 자동으로 새로고침됩니다.
(기록을 입력하는 중이면 새로고침하지 않고 "새 버전이 준비됐어요" 막대만 띄웁니다.)
